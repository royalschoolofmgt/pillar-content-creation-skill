## Phase 1: Daily Content Checklist

- [ ] **1.1** Create Section 1 — BEFORE WRITING:
  - [ ] Review keyword brief for the day's content piece
  - [ ] SERP research — search the target keyword and analyze top 3 results
  - [ ] Identify assets needed (screenshots, data, product demos)
  - [ ] Check internal linking targets (which pages to link to/from)
  - [ ] Review competitor content on the same topic

- [ ] **1.2** Create Section 2 — WRITING (AI-ASSISTED):
  - [ ] Draft content matching the SERP-validated format
  - [ ] Write unique intro (no generic AI openings)
  - [ ] Include product screenshots or demo references
  - [ ] Add data points, stats, or original insights
  - [ ] Write meta title (60 chars) and meta description (155 chars)
  - [ ] Write FAQ section targeting PAA questions

- [ ] **1.3** Create Section 3 — INTERNAL LINKING:
  - [ ] Add link to parent pillar page
  - [ ] Add 2-3 cross-pillar spoke links
  - [ ] Add CTA buttons (shop now, browse products, view deals)
  - [ ] Add related articles section at bottom
  - [ ] Verify all links work

- [ ] **1.4** Create Section 4 — TECHNICAL SEO:
  - [ ] Add schema markup (Article, FAQ, HowTo as appropriate)
  - [ ] Set canonical URL
  - [ ] Optimize images (alt text, compression, descriptive filenames)
  - [ ] Verify heading structure (H1 → H2 → H3 hierarchy)
  - [ ] Check URL slug matches target keyword

- [ ] **1.5** Create Section 5 — PUBLISH & AMPLIFY:
  - [ ] Submit URL to Google Search Console for indexing
  - [ ] Share on social media (Instagram, TikTok, Facebook)
  - [ ] Post in relevant communities/forums
