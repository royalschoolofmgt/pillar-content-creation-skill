## Phase 1: Calendar Structure

- [ ] **1.1** Determine deployment speed based on brand capacity
- [ ] **1.2** Set start date and end date for the calendar
- [ ] **1.3** Define publishing phases:
  - [ ] Phase 1 (LAUNCH BLITZ): All pillar pages + highest-volume spokes

  - [ ] Phase 4 (DOMINANCE): Remaining spokes + refresh top performers
- [ ] **1.4** Set daily publishing capacity (pieces per day)

- [ ] **2.1** Assign pillar pages to Phase 1 dates (publish first)

## Phase 3: KPI Tracker

- [ ] **3.1** Build weekly KPI tracker for 13 weeks
- [ ] **3.2** Define KPI columns:

  - [ ] Organic Impressions
  - [ ] Organic Clicks

## Rules

1. **Sequential execution only** — complete each step before moving to the next
2. **Highest volume first** — always prioritize highest-volume keywords earliest
3. **Pillars before spokes** — pillar pages publish before their spokes
4. **No back-to-back same pillar** — spread pillar coverage across days
